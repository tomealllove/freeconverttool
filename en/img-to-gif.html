How to make a GIF from images

  1. Upload two or more images - the upload order is the playback order, and you can reorder or remove frames.
  2. Set the frame delay; a smaller value plays faster, and keeping every frame equal makes playback smoother.
  3. Adjust the output size and loop count, where 0 means it loops forever.
  4. Generate the GIF, preview it, then download.

FAQ

How many images do I need?

Two or more. More images and larger sizes mean a bigger file and a longer wait.

The GIF is too large, what can I do?

Reduce the output size, drop some frames or increase the frame delay. GIF only supports 256 colors, so detailed photos tend to be heavy - compress them beforehand if needed.

Can I limit how many times it plays?

Yes. A loop count of 0 loops forever, while any number stops playback after that many runs.

Is my image uploaded anywhere?

No. No uploads, no retention. Your privacy is fully protected.
