How to merge or split PDF files

  1. Pick Merge mode or Split mode at the top of the page - both options are shown side by side.
  2. Merge mode: select several PDFs at once, then use the up and down arrows to reorder them or remove the ones you do not need.
  3. Split mode: upload one PDF and choose either a fixed number of pages per part or custom page ranges such as 1-3,4-8,9-12.
  4. Click Merge or Split, then download each file separately or grab them all in one ZIP.

Frequently asked questions

In what order are the files merged?

Files are merged from top to bottom in the list. Use the up and down arrows to change the order, or remove files you do not want.

How many PDFs can I merge at once?

There is no fixed limit; each file must be under 100MB. The more pages you have, the longer it takes, so merging in batches is a good idea.

How do I write page ranges?

Separate ranges with commas and write each part as start-end, for example 1-3,4-8,9-12. A single number exports just that page. Each range becomes its own PDF.

Is my file uploaded to a server?

No. No uploads, no retention. Your privacy is fully protected.
