How to compress an image

  1. Select one or more images in the upload area, or drag them onto the dashed box.
  2. Pick a mode: quality mode to set the output percentage yourself, or target size mode where you enter the KB you need and the tool gets as close as it can.
  3. Optionally set the output format (keep original, JPG or WebP) and a maximum side limit such as 1920, 1280 or 800 px.
  4. Start compressing, compare the size before and after, then download what you are happy with.

FAQ

Which mode should I use, quality or target size?

Use quality mode for consistent looking results across a batch. Use target size mode when a form imposes a hard limit such as 200KB - the tool finds the closest settings automatically.

Will the image still look good?

JPEG and WebP are lossy, so lower quality means a smaller file. Anything between 60 and 80 is usually hard to tell apart from the original. Check the preview before going lower.

Which formats are supported?

JPG, PNG and WebP input is supported. You can keep the original format or convert everything to JPG or WebP for a smaller result.

Is my image uploaded anywhere?

No. No uploads, no retention. Your privacy is fully protected.
