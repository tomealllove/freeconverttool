How to compress a PDF

  1. Click the upload area to pick a PDF, or drag the file into the box. Files up to 100MB are supported.
  2. Pick a method: Light keeps the text selectable, while Reprint turns every page into a JPEG for a much bigger reduction.
  3. In Reprint mode you can also set the resolution, switch to grayscale and tune the JPEG quality. Choose 72 DPI plus grayscale for the smallest file.
  4. Click Compress, compare the before and after size, then download the compressed PDF.

Frequently asked questions

What is the difference between the two modes?

Light mode only rebuilds the PDF structure and clears title and author metadata, so text stays selectable and searchable and the saving is modest. Reprint mode renders every page as JPEG, which saves far more but turns text into an image you can no longer search.

Why did the file get bigger?

PDFs that are mostly vector text naturally grow once they are rasterized. Lower the resolution, turn on grayscale or drop the JPEG quality, or use Light mode for this kind of document.

Will compression damage my original file?

No. The original file is left untouched and the result is saved as a new file you download.

Is my file uploaded to a server?

No. No uploads, no retention. Your privacy is fully protected.
