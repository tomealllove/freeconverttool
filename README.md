## 本地预览

推荐用本地服务器（兼容性最佳）：

```bash
python -m http.server 8000
# 或
npx serve .
```

然后访问 `http://localhost:8000`。

> 以 `file://` 直接双击打开时，个别浏览器会拦截跨域 Worker，导致「图片转 GIF」无法启用；其余功能不受影响，PDF 相关页面已内置 Blob 兜底。用 http 方式打开则全部正常。

## 已知边界

- **PDF 转 Word**：适合文本型 PDF；多栏、表格、图文混排还原度有限；扫描件无文本层，本工具不做 OCR。
- **PDF 压缩**：「轻度」仅重写结构与元数据；「重印」会把文字转为图片（不可选中、不可搜索）。
- **MOBI / AZW3**：私有格式，前端无可用解析库，页面会明确提示先用 Calibre 转 EPUB。
- **音频**：浏览器原生无 AAC / FLAC 编码器，这两种格式需走 ffmpeg.wasm 高级模式。
- **视频**：ffmpeg.wasm 无硬件加速，适合短视频；长视频建议用专业工具。
- **证件照**：AI 抠图需联网加载模型，失败时自动回退为纯色容差抠图。
