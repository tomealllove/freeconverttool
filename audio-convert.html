如何使用音频格式转换

  1. 点击上传区选择音频，或把文件拖拽到虚线框内（建议 200MB 以内）。
  2. 选择目标格式：WAV（无损 PCM）或 MP3，可按需指定采样率与 MP3 码率。
  3. 点击「开始转换」，完成后可直接试听，满意再点「下载」保存。

常见问题

支持哪些音频格式？

输出目前提供 WAV 与 MP3 两种。浏览器能解码的常见格式（MP3 / WAV / OGG / M4A 等）都可以作为输入；OGG / AAC / FLAC 因为没有通用的前端编码器，暂不支持输出。

转换会损失音质吗？

转为 WAV 采用无损 PCM 封装，音质与源文件完全一致，体积会变大；转为 MP3 属于有损压缩，音质由所选码率决定（128 / 192 / 320 kbps），码率越高越接近原音、文件也越大。

音频会上传到服务器吗？

不会。全部转换在你的浏览器本地完成，即开即用不留存，隐私安全有保障。

为什么提示无法解码？

说明该音频的编码（如 FLAC / WMA / AIFF 等）当前浏览器不支持解码。请先用其它工具转成 WAV 或 MP3 后再上传，或换用 Chrome / Edge / Safari 新版本重试。
